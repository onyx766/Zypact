# Archived Zypact Documentation

Files in this directory are historical records only. They preserve repository and decision history; they do not define current product scope, methodology, engineering work, sales claims, pricing, or acceptance criteria.

Use the active canonical package listed in the repository [`README.md`](../../README.md).

Every file in the dated pre-reset archive begins with a superseded banner. Old requirements—including fixed three-run client measurements, `won/partial/lost` commercial verdicts, mandatory founder delivery, broad AI Buyer Journey Intelligence promises, and historical contractor-estimate structures—are not active.
